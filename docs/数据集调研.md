# 遥感智能体公开数据集与 SOTA 调研

调研日期：2026-09-16

本文关注大模型驱动的遥感／地球观测（Earth Observation，EO）智能体，覆盖工具调用、工作流规划、代码执行、科学分析，以及支撑这些能力的视觉语言数据。

## 1. 阅读口径与主要结论

**建议优先使用 OpenEarthAgent 训练工具轨迹，以 ThinkGeo、Earth-Bench、UnivEARTH 评估不同类型的智能体能力，再用 AutoGEEval++ 检查 GEE 编程能力。** GeoChat、SkyScript、LHRS-Align、TEOChatlas 主要解决感知与指令训练问题，不能代替执行型智能体评测。

本文将“当前 SOTA”限定为截至调研日能从官方榜单、方法论文或官方仓库核实的最好公开结果，并标明证据等级：

- **L：官方榜单最高值**。只对该榜单已收录方法、指定指标有效。
- **P：已检索论文中的最佳公开报告值／SOTA 候选**。有原始论文和具体数值，但不等同于独立复现或全领域穷尽验证。
- **B：已核实基线或原论文最佳**。不能确认其仍为当前 SOTA，明确保留这一限制。
- **N/A：不适用**。例如纯预训练语料没有独立的统一排行榜；不以其训练出的模型在其他数据集上的成绩冒充该数据集 SOTA。

表中的“大小”分别指任务数、图像数、图文对数、QA 数或轨迹步骤数，不能相加比较。未下载完整数据包，因此不估算 GB/TB。Accuracy、OA、AA、F1 越高越好；RMSE 越低越好。CIDEr 是相似度评分，不是正确率，即使采用 ×100 展示也不应解读为百分比正确率。

## 6. 如何构建自己的遥感智能体数据集

以下是结合上述基准形成的实施建议，不是任何单一数据集的官方标准。

| 步骤                  | 需要保存的内容                                                                    | 可验证的质量要求                                                                |
| --------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 1. 定义问题与成功条件 | 任务 ID、自然语言问题、区域 AOI、时间、期望产物、科学假设、允许误差               | 专家确认问题有实际意义、可由允许的数据求解；明确是否允许“不足以判断”          |
| 2. 固定数据版本       | 原始来源、产品 ID、时间戳、CRS、GSD、波段、单位、比例因子、NoData／质量掩膜、许可 | 核验空间配准、云覆盖、传感器差异、时相匹配；保存本地快照或可重建清单            |
| 3. 建立工具协议       | 工具 schema、版本、参数单位、坐标约定、输出格式、错误类型、执行环境               | 对 NDVI、面积统计、检测、分割、投影等工具独立测试；确认工具错误和规划错误可区分 |
| 4. 专家执行参考工作流 | 依赖关系、调用及参数、中间文件、最终数值／地图、执行日志、可接受替代方案          | 实际运行并回放；用确定性计算校验结果；不把未运行的模型生成轨迹视为 gold         |
| 5. 扩展语言与任务难度 | 同义问题、跨区域／跨时相／跨模态任务，多轮追问，错误恢复及不可解任务              | 每题人工审核；检查无图／无工具捷径；不在题目中泄露正确工具顺序                  |
| 6. 防止数据泄漏       | 原图到裁片、场景到事件、衍生 QA 到原图的血缘，训练／验证／测试 ID                 | 按地域、时间、事件、原始场景划分；验证相邻裁片和同事件影像不会跨集              |
| 7. 分层评测           | 最终产物质量、数值／几何误差、调用参数正确性、完成率、恢复率、成本、耗时          | 优先程序化判定；开放文本的 LLM 裁判先经人工校准；报告多次运行均值与方差         |

一个实用的数据样本至少应包含：任务 ID、划分、查询、数据清单、AOI、时间范围、工具 schema 版本、参考工作流、观察、答案、产物、验证规则、数据血缘和许可。参考工作流可以有多个有效解；不宜仅因调用顺序与单条 gold 不同而将科学上正确的结果判错。

## 8. 检索方法与局限

本次使用 AI 辅助检索与整理，优先核查原始论文、会议论文、作者仓库、Hugging Face 数据卡和作者维护榜单。以数据集名称结合 benchmark、dataset、results、SOTA、accuracy、2025、2026 搜索，并沿后续方法论文检查对旧基准的结果。二手综述仅作发现线索，不作为关键 SOTA 数字的唯一依据。

本次没有下载全部影像、重新训练模型或执行完整 benchmark，也没有完成系统综述意义上的穷尽检索。P 级结果是作者报告、未独立复现的候选；B 级和 N/A 项不能被引用为已确认的当前 SOTA。部分最新论文没有统一排行榜，RSVQA 的较新 DRL 成绩仍待完整原表核实。所有表内数值均保留直接来源链接及协议限制，后续更新应同时记录数据版本、模型版本、工具环境和判分程序，而不只替换一个数字。
